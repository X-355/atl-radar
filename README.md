# ATL Radar

How close the biggest coins are to their all-time lows on Binance, with a liquidation-below-ATL calculator and the order book near the low. One HTML page; it reads Binance's public API live in the visitor's browser.

Research, not financial advice.

Pages: `index.html` (ATL Radar), `methodology.html` (how ATL Radar works), `lab/` (Research Lab) and `lab/methodology.html` (how the Research Lab is measured).

Live at https://radar.cointelescope.org (GitHub Pages, custom domain set by the CNAME file; DNS: CNAME radar -> x-355.github.io, DNS only, in Cloudflare).
